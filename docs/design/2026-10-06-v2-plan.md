# monoLS v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the real v1 bugs in place, then build twin Python and MATLAB/Octave implementations of the v2 design.

**Architecture:** Fitted values are z = A·w with w ≥ 0, where A is the corrected basis, applied in O(n·k) through
spacing-weighted cumulative sums and never stored. Order 0 is solved by PAVA, order ≥ 1 by a structured
Lawson–Hanson active-set solver, and L1 by IRLS on top of that. Golden JSON fixtures produced by an
independent dense reference solver keep the two languages in lockstep.

**Tech Stack:** Python ≥ 3.9 + numpy (tests: pytest, scipy, scikit-learn); MATLAB R2019b+ / Octave ≥ 7, base functions only.

**Spec:** `docs/design/2026-10-06-v2-design.md`

## Global Constraints

- Every task ends in exactly one commit (more only where a task says so), and each commit is pushed to `origin v2` right after.
- No toolboxes (MATLAB) and no runtime dependency beyond numpy (Python).
- Defaults: `order=0`, `direction='auto'`, `curvature='saturating'`, `loss='l2'`, `boundary=0`, `tol=1e-10`, `max_iter=10*n`.
- L1 IRLS: ε₀ = 1e-3·MAD(y), halve each iteration, floor 1e-10·scale, stop when relative objective change < 1e-8 or after 50 iterations.
- Fixture parity: |z − z_ref| ≤ 1e-8·range(y) (L2); for L1, relative loss difference ≤ 1e-6.
- Knot location reported = mean of the stencil x_j … x_{j+k+1} of the active (k+1)-th divided difference (symmetric under reversal of x).
- The intercept is a free variable that is always in the active set (equivalent to the ±1 column pair in the spec).

## Review Focus

- Constant y (zero range): expect a constant fit, no divide-by-zero. Tested in Tasks 9 (Python) and 16 (MATLAB).
- Fewer unique samples than order+2: expect a valid fit, exact interpolation of the data when allowed. Tasks 9 and 16.
- All-NaN y, or a single valid sample: expect NaN output, or a constant. Tasks 9 and 16.
- MATLAB row-vector y (1×n): treated as one series, not n series. Task 16.
- Large n (2·10⁴, order 2): finishes without allocating n×n. Tasks 9 and 16.

### Task 12 (Python): structured active-set solver
**Files:** `python/src/monols/_activeset.py`, `python/tests/test_activeset.py`.
**Produces:** `solve_canonical(x, y, w, k, *, excluded_tail=0, tol=1e-10, max_iter=None) -> Solution(z, coef, active: ndarray[int], converged: bool, kkt: float, n_iter: int)`.
- Lawson–Hanson as in the spec: the entering column has the largest gradient/proxy; the LS subproblem uses `numpy.linalg.lstsq` on unit-normalized active columns; a column that leaves immediately after entering is skipped for that outer iteration; tolerance is relative to sqrt(Σw(y−ȳ)²) (scale 0 → return the weighted mean).
- [ ] Tests: agrees with dense scaled `scipy.optimize.nnls` within 1e-8 (k = 1..4, n = 200, irregular x); KKT ≤ 1e-10; n = 20000, k = 2 finishes in < 10 s.
- [ ] Commit: `feat(python): structured Lawson-Hanson solver`.
